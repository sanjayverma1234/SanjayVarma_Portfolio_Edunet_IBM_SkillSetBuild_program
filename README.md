🌐 Sanjay Varma S – Portfolio

An interactive, modern, and responsive personal portfolio website showcasing my skills, projects, and professional background.
Built with HTML, CSS, JavaScript, GSAP, ScrollMagic, and EmailJS to deliver a dynamic and smooth user experience.

🚀 Features

Responsive Design – Optimized for desktop, tablet, and mobile devices.

Smooth Animations – ScrollMagic + GSAP for fade-ins, progress bars, and project reveals.

Dark Mode Toggle – User preference stored with localStorage.

Projects Showcase – Dynamic rendering of portfolio projects with live demo & GitHub links.

Contact Form Integration – EmailJS-powered contact form to receive messages directly.

Konami Code Easter Egg 🎮 – Fun hidden gradient animation on secret input.

SEO Optimized – Includes meta tags and Open Graph for better visibility.

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (ES6)

Animations: GSAP, ScrollMagic

Forms: EmailJS

Icons: FontAwesome

Version Control: Git & GitHub

⚡ Setup & Usage

Clone Repository

git clone https://github.com/yourusername/portfolio.git
cd portfolio


Open in Browser
Simply open index.html in any modern web browser.

Run with Live Server (Optional)
If you have VS Code installed:

Install Live Server extension.

Right-click index.html → Open with Live Server.

🔑 Configuration

EmailJS Setup

Replace emailjs.init('YOUR_USER_ID') with your EmailJS USER_ID.

Update service_xxx and template_xxx with your EmailJS Service & Template IDs.

GitHub Projects Fetch (Optional)

In script.js, update:

fetch('https://api.github.com/users/sanjayverma1234/SanjayVarma_Portfolio_Edunet_IBM_SkillSetBuild_program/new/main2')
